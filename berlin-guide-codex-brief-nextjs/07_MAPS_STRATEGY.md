# Maps Strategy

## 1. Recommendation

Use **Leaflet + OpenStreetMap** as the embedded map system.

Use **Google Maps external links** for navigation and directions.

Do not use Google Maps JavaScript API as the primary embedded map for this project.

## 2. Why Leaflet/OpenStreetMap

Benefits:

- no API key;
- no billing;
- no backend;
- simple markers;
- category filters;
- popups;
- works well in static apps;
- good fit for personal travel guides.

## 3. Why not Google Maps API as main map

Google Maps API can be excellent, but for this project it adds unnecessary complexity:

- API key management;
- billing setup;
- quota considerations;
- environment variables;
- more vendor coupling.

For a personal guide, that is overkill.

## 4. Google Maps links

Use generated links for:

- opening a place;
- walking directions;
- public transport directions;
- cycling directions.

Example URL patterns can be generated by utility functions.

### Place search URL

```text
https://www.google.com/maps/search/?api=1&query={encodedQuery}
```

If coordinates exist:

```text
https://www.google.com/maps/search/?api=1&query={lat},{lng}
```

### Directions URL

```text
https://www.google.com/maps/dir/?api=1&origin={origin}&destination={destination}&travelmode={mode}
```

Supported modes:

- walking;
- transit;
- bicycling;
- driving.

## 5. Public transport links

Include external links to:

- BVG journey planner;
- VBB route planner;
- Google Maps transit;
- Citymapper if relevant.

For MVP, static external links are enough.

## 6. Bike rental

Bike rental should be documented in the Transport section.

Data should support:

- provider name;
- app/website link;
- notes;
- verification status;
- recommended use case.

Avoid claiming a provider is the best unless verified.

## 7. Marker categories

Recommended marker categories:

- accommodation;
- vegetarian food;
- restaurants;
- cafés;
- supermarkets;
- museums;
- art/galleries;
- street art;
- alternative;
- nightlife;
- parks/walks;
- transport.

## 8. Data requirements for markers

A place can be shown on the map only if it has coordinates.

If coordinates are missing:

- show the place in lists;
- hide from map;
- optionally display “coordinates missing”.

## 9. Technical notes for Next.js

Leaflet uses browser APIs, so map components must be client components.

Use:

```tsx
'use client';
```

For `react-leaflet`, if needed, use dynamic import with SSR disabled.

Also import Leaflet CSS globally or from a client-safe location.

## 10. Map fallback

The app must still be useful without the map.

Every place card should show:

- address if available;
- neighbourhood;
- Google Maps link;
- notes.
