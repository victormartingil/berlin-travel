# Manual Content Verification Checklist

Use this when adding real travel content.

## For restaurants and cafés

- [ ] Official website checked.
- [ ] Google Maps listing checked.
- [ ] Opening hours checked.
- [ ] Vegetarian suitability checked.
- [ ] Reservation need checked.
- [ ] Price level estimated.
- [ ] Coordinates added.
- [ ] Source URL added.
- [ ] `lastVerifiedAt` updated.

## For museums

- [ ] Official website checked.
- [ ] Opening hours checked.
- [ ] Ticket/reservation link checked.
- [ ] Closing days checked.
- [ ] Estimated visit duration added.
- [ ] Source URL added.
- [ ] `lastVerifiedAt` updated.

## For nightlife/events

- [ ] Event date checked.
- [ ] Venue checked.
- [ ] Music style checked.
- [ ] Ticket/source link checked.
- [ ] Door/practical notes checked if available.
- [ ] Transport at night considered.
- [ ] `lastVerifiedAt` updated.

## For transport

- [ ] Official planner links checked.
- [ ] Airport route checked.
- [ ] Nearby stations checked.
- [ ] Bike rental providers checked.
- [ ] Night transport notes checked.

## For itinerary

- [ ] Day plan is geographically coherent.
- [ ] Walking distances are realistic.
- [ ] Lunch/dinner options are nearby.
- [ ] Rain alternatives exist.
- [ ] Tired-day alternatives exist.
- [ ] Reservations/tickets are noted.
